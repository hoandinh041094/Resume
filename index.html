How I work

Three rules I actually hold to.

Business first

Learn the P&L before touching the query

Analysis is not the product. A better decision is. I want to know how the vertical makes money and where it leaks before I decide what is worth measuring.

Build once

If we run it twice, it becomes a pipeline

Recurring work belongs in version control with an owner and a test, not in a workbook someone rebuilds each month. That is what buys the team room to think.

Say the number

End with a recommendation, not a description

A weekly report that explains what happened is a summary. Stakeholders need the read and the call. I train the team to write the last slide first.
